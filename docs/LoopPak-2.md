## 🎯 10주간 뭘 배웠나요?

커밋 기록을 보니 **159개의 기능 구현/개선 커밋**이 있더라고요. 이커머스 서비스를 처음부터 끝까지 만들면서 정말 다양한 걸 경험했어요.

**Round 1-2:** Spring Boot + Kotlin 기본기 (CRUD, JPA, REST API)
**Round 3-4:** 도메인 설계 (Aggregate, 이벤트, 트랜잭션 경계)
**Round 5-6:** 장애 처리 (Resilience4j, Circuit Breaker, Fallback)
**Round 7-8:** 이벤트 & 메시징 (Kafka, Outbox 패턴, 코루틴)
**Round 9-10:** 성능 최적화 & 배치 (Redis 랭킹, Spring Batch)

**기술 스택:** Spring Boot, Kotlin, Kafka, Redis, Spring Batch, Docker

**어떻게 성장했나요?**
Before: 일단 되게만 만들자
After: 도메인 설계부터, 트랜잭션 경계 고민, 테스트 작성, 성능 고려

코드 한 줄 한 줄에 의미가 생겼어요. "왜 이렇게 짰는가?"에 대한 답을 할 수 있게 됐죠.

## 🌟 가장 인상 깊었던 프로젝트

**Round 8: Kafka + Transactional Outbox 패턴**이 제일 기억에 남아요.

처음엔 "이벤트를 발행했는데 DB 커밋이 실패하면?" 같은 문제를 고민한 적이 없었어요. 근데 실제로 분산 시스템에서 데이터 정합성을 어떻게 보장하는지 Outbox 패턴으로 직접 구현하면서 "아, 실무에서 이런 문제가 생기는구나" 하고 체감했습니다.

**왜 이 프로젝트가 인상 깊었나요?**
- 실무에서 필수인 분산 시스템 데이터 정합성 보장
- Kafka Producer/Consumer 전체 파이프라인 구축
- Dead Letter Queue, 멱등성 보장 같은 실제 문제 해결
- "DB 트랜잭션 + 메시지 발행"을 원자적으로 처리하는 방법 체득

면접에서도 "분산 트랜잭션을 어떻게 처리했나요?" "Kafka 메시지가 중복으로 들어오면 어떻게 하나요?" 같은 질문에 자신 있게 답할 수 있었어요.

## 💡 루프팩 부트캠프의 특별함

기술은 혼자서도 배울 수 있어요. 근데 루프팩은 **단순한 강의가 아니었어요**.

### 열정적인 멘토들

멘토님들의 **엄청난 실력과 열정적인 지도**가 정말 인상 깊었어요. 실무 경험 기반 피드백, 깊이 있는 리뷰, "왜 이렇게 설계했는지 설명해주세요" 같은 사고력 자극. 단순히 코드만 봐주는 게 아니라 함께 고민하게 만드셨어요.

### ZEP에서 팀원들과 친해지기

처음엔 "온라인으로 친해질 수 있을까?" 걱정했는데, **ZEP 덕분에 오프라인처럼 친해질 수 있었어요**. 가상 오피스에서 자연스럽게 대화하고, 함께 코딩하고, 주말에 "오늘도 열코 합시다!" 하면서 서로 응원했어요 😊

### 서로 독려하고 응원하는 문화

**우리 팀뿐만 아니라 다른 팀원들도** 정말 함께 성장하려고 노력하는 모습이 인상 깊었어요. 막힌 부분 같이 해결하고, 자료 공유하고, **서로 독려하고 응원하는 분위기** 💪

온라인 부트캠프라고 걱정했는데, 오히려 전국 각지의 다양한 분들과 교류할 수 있어서 좋았습니다. 혼자였으면 중간에 포기했을 거예요.

### 개발자 동료를 얻을 수 있음

루프팩의 가장 큰 장점은 **기술 성장 + 개발자 네트워크**를 동시에 얻을 수 있다는 거예요. 온라인 부트캠프를 통해서 기술만 배우는 게 아니라, **같은 목표를 가진 개발자 친구들**을 만날 수 있었어요. 지금도 가끔 연락하면서 서로 공부 내용 공유하고 있습니다.
