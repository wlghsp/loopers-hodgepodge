커맨드 vs 이벤트

행동 주체

여자친구가 삐졌어.
-> 내가 알아서 눈치채야함. (이벤트 : 여자친구가 삐졌다.)
-> 여자친구가 나 삐졌어. 너 나랑 놀이공원 안가주면 우리 헤어져. (커맨드 : 놀이공원 가자.)

커맨드
A 가 B 에 대해서 알고 있다. 명확하게 B 가 뭘 했으면 좋겠다. 라는 내용의 메세지를 남김.

이벤트
A 는 B 에 대해서 알 필요가 없다. 내가 어떤 상태인지, 혹은 어떤 행위를 했는지 메세지를 남김.

이벤트가 좀 더 확장성 면에선 커맨드보다 풍부할 것이다.
커맨드 : 누구한테 시킬지를 알아야 하잖아?!
        그 누구가 많아질 수록 (시스템의 복잡도가 높아질 수록) 내 복잡도가 증가함.
				"독재"
				Application 계층에서 커맨드 방식으로 각 도메인들을 조율.
이벤트 : 나는 내 맥락까지만 알면 됨.
				내가 관심있는 사람한테 귀기울여야 함.
				주문이 발생했다. <- 결제 x 재고가 관심 있어야 함.
				결제가 취소되었다. <- 주문이 상태를 변경함.(취소로) <- 재고가 어 내 재고 원복
